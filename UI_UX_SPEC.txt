1. DESIGN SYSTEM
--------------------------------------------------------------------------------

FRAMEWORK STACK
  - Next.js 14 + React 18 + TypeScript 5
  - Tailwind CSS 3
  - shadcn/ui (Radix UI primitives)
  - Framer Motion (animations)
  - Recharts (data visualisation)
  - ReactFlow (graph/network visualisation)

  - UI text: Inter (Google Fonts)
  - Code / IDs: JetBrains Mono

THEME

5. FRAUD NETWORK GRAPH (ReactFlow)
--------------------------------------------------------------------------------

Component: FraudNetwork
Props: data (GraphData), className

NODE TYPES (all use same AccountNode renderer):
  account      — User icon
  entity       — Building2 icon
  device       — Smartphone icon
  transaction  — CreditCard icon

NODE VISUAL STYLE
  Rounded rectangle (rounded-xl), min-width 140px
  Background: card colour
  Shadow: coloured glow matching risk score
  Border: 2px, colour = risk score colour
    risk >= 80  →  border-red-500    shadow-red-500/20
    risk >= 60  →  border-orange-500 shadow-orange-500/20
    risk >= 30  →  border-yellow-500 shadow-yellow-500/20
    risk < 30   →  border-green-500  shadow-green-500/20
  Flagged nodes: ring-2 ring-red-400 ring-offset-2 (extra red ring around border)
  Node content:
    Icon (top-left) + Label (account name, small bold) + ID (10px, muted)
    Risk score (coloured text, bold)
    "Flagged" destructive badge (if flagged)
  Handles: Left (target) + Right (source), muted-foreground colour

EDGE STYLE
  Normal edges:    gray stroke, 1.5px, arrow marker (gray)
  Suspicious edges: red (#ef4444) stroke, 2.5px, animated (marching ants), arrow marker (red)
  Label: formatted currency amount (₹) in small text
  Label background: card colour (semi-transparent)

LAYOUT ALGORITHM
  Circular layout — nodes evenly distributed on a circle
  Radius = max(250, nodeCount × 40)
  Nodes positioned at angle = (2π × i / nodeCount) − π/2

CONTROLS
  ReactFlow built-in Controls (bottom-left): zoom in/out/fit
  ReactFlow MiniMap (bottom-right):
    Node colours match risk score (red/orange/yellow/green)
    Mask: background colour at 70% opacity
  Background: dot grid, gap 20, size 1

CANVAS
  Height: 500px
  fitView on load (padding 0.2)
  minZoom: 0.3 | maxZoom: 2
  Attribution hidden (proOptions.hideAttribution)

9. INTERACTION PATTERNS
--------------------------------------------------------------------------------

DATA FETCHING
  All via useEffect + fetch() (no SWR / React Query)
  Pattern: setLoading(true) → fetch → setData → setLoading(false)
  Errors: caught, console.error, conditional empty/error state UI

LOADING STATES
  Full-page loads: DashboardSkeleton component
  Inline loads: Skeleton component (animated pulse)
  Button loads: spinner icon replaces button icon, disabled

ANIMATIONS (Framer Motion)
  Page sections: motion.div with initial={{ opacity: 0, y: 20 }} animate={{ opacity: 1, y: 0 }}
  Stagger: each card delays by 0.1s × index
  Transition: spring or ease, ~0.3s

REAL-TIME
  Pre-txn queue: setInterval every 15 seconds
  Header clock: setInterval every 1 second (IST time)

NAVIGATION
  Programmatic: useRouter().push(path)
  Links: Next.js <Link> component
  External (PDF): window.open(url, '_blank')

FORMS
  Fully controlled: useState per field
  Validation: basic (required, min length) — no form library
  Submit: async function, try/catch, loading state

NOTIFICATIONS / TOASTS
  None implemented — errors shown as inline error cards/callouts

TABS
  shadcn/ui Tabs component
  Default active tab: first tab
  Tab state: local component state (not URL)

PAGINATION
  Local state: page number + page size
  Controls: "Previous" / "Next" buttons + "Page X of Y" text
  No URL-based pagination
